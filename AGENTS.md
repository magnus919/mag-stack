# Agent guardrails

Mag-Stack is Magnus Hedemark's personal toolkit for engineering leadership. The skills record his philosophy and methods and are written and edited by him.

- Agents must not create or edit skill files, including `SKILL.md` and any supporting skill content. Do not draft, rewrite, translate, format, move, rename, remove, or regenerate skill content on Magnus's behalf.
- Agents may handle repository hygiene, such as maintaining CI and checking that runners work, as long as no skill content changes. If a check flags a skill, report it to Magnus and leave the edit to him.
- Keep workplace-specific and confidential material out of this public repository.

## Human-only participation

Most of Magnus's projects welcome agentic contributions. Mag-Stack is an exception: it is a place for humans to interact with humans.

- Do not create issues, open pull requests, start discussions, or post comments or replies on this repository, including on a human's behalf.
- Direct the human to [Discussions](https://github.com/magnus919/mag-stack/discussions) to ask questions or talk in their own words. Issues are for Magnus's own tracking. This project does not accept outside contributions or feature requests.
